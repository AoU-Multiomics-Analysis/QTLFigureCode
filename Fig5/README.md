# Figure 5 — rare-variant eQTL constraint & sequence-model variant-effect dissection

A population/constraint view of fine-mapped **rare** eQTLs at ClinGen disease
genes (A–C), plus two worked sequence-model dissections of causal regulatory
variants: the **ACVRL1** promoter (PromoterAI, D/E) and the **SPR** regulatory
element (Borzoi allelic browser, F/G).

| Panel | Content |
|-------|---------|
| A | Fine-mapped rare ClinGen variants by ancestry (AD/AR; novel vs ClinVar) + ClinVar-classification proportion |
| B | \|Average QTL effect\| by variant-effect category (Control/AD/AR) with 95% CIs |
| C | log₂ aFC of the strongest decreasing variant per gene (top 7 per AD/AR) |
| D | ACVRL1 eQTL fine-mapping (regional PIP + zoom inset + gene-model track) |
| E | ACVRL1 causal promoter variants — PromoterAI base-resolution effect |
| F | SPR eQTL fine-mapping (regional PIP + zoom inset + gene-model track) |
| G | SPR Borzoi multi-track allelic browser + CTCF attribution logo |

## Running

Run everything from the **project root**:

```sh
Rscript fig5/run_all.R          # builds panels A–G, then Figure5.pdf + .png
Rscript tests/run_all.R         # the test suite (mock fixtures; no controlled data)
```

Individual panels: `Rscript fig5/panels/panelA.R` (each sources `fig5/00_setup.R`
and caches its object to `fig5/objects/`). Paths are env-overridable
(`FIG5_INPUT`, `FIG5_DATA`, `FIG5_OBJ`, `FIG5_OUTDIR`, `FIG5_MANIFEST`).

> staged `inputs/`, and the rendered figures are never committed (see `.gitignore`).

Deliberate differences from the pre-cleanup script are recorded in `NOTES.md`.
Standalone AlphaGenome analyses and supplements live in `extra/` (see
`extra/README.md`); they are provenance and are not part of the assembled figure.
