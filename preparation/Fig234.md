# Figures 2-4 preparation

These scripts use the result-table paths in `Fig2/inputs.tsv`, `Fig3/inputs.tsv`,
and `Fig4/inputs.tsv`. The local reader in `Fig3/result_io.R` checks staged
files. It does not download files or reuse a disk cache to skip computation.
Pure transformation functions come from the original figure code. Current
methods and source hashes are listed in the preparation manifest.

## Figure 2

`fig2_data` prepares four frequency bins, unique-variant ancestry tests,
consequence-priority aFC data and regressions, cumulative effects, outlier
statistics, and gene-burden medians. It also prepares S16 frequency-bin and
rolling-mean summaries. Source result rows and source contingency counts are
the starting points. The association and outlier classifications that produced
those inputs remain upstream analysis results.

The frequency-panel unit is a variant-trait pair. The bin boundaries are 1%, 5%,
and 10%. Other panels can collapse variants across assays. Cumulative effects
are ordered within gene and direction. The expression cap is applied before
the display percentages. The outlier step preserves the original half-cell
odds-ratio correction and Fisher test on the original counts.

`fig2_notebook` connects these results to the current plot inputs. It checks
prepared scientific frames and data-bearing layers against the accepted layout
reference, replaces those values, and writes `Science_display_plots.rds` and
the S16 plot object to the generated overlay.

## Figure 3

`fig3_coloc` reads the three SuSiE tables and gene, credible-set, and variant
colocalization tables. It applies the original Bayesian FDR calls and prepares
signal components, effect-model input, per-assay rates, credible-set-pair rates,
and MAF regression estimates. Gene, pair, and variant denominators are kept
separate. MAF is folded within each population before the maximum is taken.

`fig3_annotations` builds the symmetric variant universe and annotation-model
fits. It retains the original conservation and TSS-distance thresholds.
`fig3_notebook` writes the five plot objects from these results. The source
methods and synthetic tests cover FDR ties, missing probabilities, the
geometric PIP weight, Wilson intervals, and the unstandardized log10-MAF model.

## Figure 4

`fig4_traits` contains the gene-count and lenient union-rate preparation for A.
Its required full harmonized gene table is missing locally. A three-column
membership export is not a substitute for that table.

`fig4_twas` prepares B-D from TWAS and conditional-TWAS results, drug
interactions, and ClinGen annotations. It preserves the heritability filter,
AF-threshold contrast, matched controls, zero-P handling, and display cap.
`fig4_notebook` connects these results to B-D plot objects. It can connect A
when the full source result has been supplied.

`fig4_loci` prepares the seven exclusive QTL intersections for S24 and the CD40
signal-to-variant joins for S25. It excludes the union summary layer and counts
unique gene-trait pairs. The CD40 join retains only participating credible
sets. Use the file overrides for the current membership and harmonized signal
exports when the staged result directory contains an older analysis.
