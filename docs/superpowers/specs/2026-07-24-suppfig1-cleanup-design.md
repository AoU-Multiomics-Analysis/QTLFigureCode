## 1. Scope

Restructure `SuppFig1/` into the modular, manifest-driven pipeline used for
Fig1/Fig3/Fig4, including its notebook. Supplemental Figure 1 compares *All of Us*
bulk RNA-seq expression to GTEx whole blood across gene types: coding-gene TPM
correlation and cohort-specific detection, GO enrichment of cohort-specific genes,
transcription-factor expression, and lncRNA expression. Several additional
per-gene-type comparisons that the original computes but does not assemble into
the main figure are **retained as standalone scripts**.

As with the figure cleanups, nothing is folded in from `QTLAnalysisUtils`; the
inline helpers move into `SuppFig1/00_setup.R`.

## 4. Shared loader extension (`common/manifest.R`)

The loader currently stages a missing file only with `gsutil cp`. It is extended
to dispatch on the `gs_uri` scheme:

- `gs://…` → `system2("gsutil", c("cp", uri, dest))` (unchanged)
- `https://…` or `http://…` → `utils::download.file(uri, dest, mode = "wb", quiet = TRUE)`

keyed off the URI prefix; anything else is an error naming the key. The
"fetch only if the local copy is missing" caching is unchanged, so a pre-staged
file is never re-downloaded. A manifest-loader test covers the https branch using
a local `file://` URI (or a `file.copy` stand-in) so tests need no network.

This benefits every figure and makes SuppFig1 fully self-staging on Terra, since
its three non-AoU inputs are public.

## 5. Folded helpers and builders

`00_setup.R` folds in the two inline helpers, fixing the issues in §7:

- `compute_mean_TPM(TPM_df, gene_annotations)` — pivots a TPM matrix long, means
  per gene, joins gene-type annotation. The unused, mislabeled `SE = sd/n` column
  is dropped.
- `plot_gene_comparison(TPM_df, point_size = 3, detection_threshold = 1,
  gene_type = "", hex = FALSE)` — the correlation-plus-detection composite;
  `stat(log10(count))` is modernised to `after_stat(log10(count))`.

Builders (`build_or_cache(name, expr, refresh = FALSE)`, identical to Fig3/Fig4):

| Builder | Builds | Inputs | Consumers |
|---|---|---|---|
| `gene_annotations()` | GENCODE v45 GTF → `gene_id` / `gene_type` (`rtracklayer::import`) | `gencode_gtf` | `merged_tpms` |
| `merged_tpms()` | AoU + GTEx per-gene mean TPM, inner-joined, gene-type attached, NA→0 | `aou_tpms`, `gtex_tpms`, `gene_annotations()` | A, B, C, D, all extras |
| `tf_list()` | human TF names | `tf_list` | C |
| `go_enrichment()` | enrichR GO terms (BP/CC/MF) for AoU- vs GTEx-specific protein-coding genes, row-bound with a `type` label — **cached so the enrichR network call runs once** | `merged_tpms()` | B |

`go_enrichment()` caches to `suppfig1/data/`; the enrichR HTTP call is invalidated
by clearing `suppfig1/data/` (or `refresh = TRUE`), documented as for Fig3/Fig4.

## 6. Panel decomposition and assembly

Main figure `SupplementalFig1.pdf`, reproduced from `SuppFig1.R` lines 208–219.
It is a 2×2 of composites; because two of them are themselves 2-plot patchworks,
`plot_annotation(tag_levels = "A")` letters **six** leaf plots — kept per the
locked decision.

| Panel | Object | Content | Tags |
|---|---|---|---|
| **A** | `protein_coding_comparison` | protein-coding AoU-vs-GTEx `log2(TPM+1)` correlation (hex) beside cohort-specific detection counts (`TPM>1` in one cohort only) | **A, B** |
| **B** | `AoU_GTEx_enrichment_plot` | top GO terms (by adjusted p) for AoU- vs GTEx-specific genes, faceted by cohort, `−log10(FDR)` with a 1.3 reference line | **C** |
| **C** | `TF_gene_comparison` | TF `log2(TPM+1)` expression boxplot, AoU vs GTEx; the lm and paired t-test are computed on the **once-logged** values (§7) | **D** |
| **D** | `lncRNA_comparison` | lncRNA AoU-vs-GTEx correlation (hex) beside detection counts | **E, F** |

```
top_row    <- protein_coding_comparison | (AoU_GTEx_enrichment_plot + theme(plot.margin = margin(l = 2, unit = "cm")))
bottom_row <- TF_gene_comparison | lncRNA_comparison
SuppFig1   <- top_row / bottom_row + plot_annotation(tag_levels = "A") &
                theme(plot.tag = element_text(size = SZ_TAG, face = "bold"))
```

Tagging happens only in `assemble.R`; no panel sets its own tag.
`tests/test_suppfig1_assembly.R` builds the figure and asserts the rendered tag
sequence is exactly `A, B, C, D, E, F`.

### Extras (`SuppFig1/extra/`)

Each script sources `suppfig1/00_setup.R`, calls `merged_tpms()`, builds its
plot(s), and saves its own PDF/PNG (they are not part of the main assembly):

- `gene_type_comparisons.R` — snRNA and miRNA comparisons via
  `plot_gene_comparison(hex = FALSE)`, filtered to `TPM > 0.1` in either cohort.
- `rrna_expression.R` — rRNA mean-TPM histogram, AoU vs GTEx.
- `hemoglobin_genes.R` — protein-coding genes whose symbol starts with `HB`,
  `log2` AoU-vs-GTEx scatter with `geom_text_repel` labels.
- `gene_type_detection.R` — count of genes detected (`TPM > 0.1`) per gene type
  from the AoU means, with the small-RNA collapse and the type filter preserved.

## 7. Defects fixed

### 7.1 Data-correctness — changes figure output

1. **TF double-log.** `TF_genes` applies `log2(x+1)` to the TPM columns
   (`SuppFig1.R:173`), and then the boxplot (`:184`), the `lm` (`:179`) and the
   paired `t.test` (`:192`) each apply `log2(·+1)` **again** — so Panel C plots and
   tests `log2(log2(TPM+1)+1)` while the axis says `log2(TPM + 1)`. Fix: drop the
   pre-transform in `TF_genes` so each of the plot, lm and t-test logs exactly
   once. Changes Panel C's values and the reported lm / t-test. Recorded in NOTES.

### 7.2 Cleanup — no result change

2. Dead staging removed: `system("wget …")` for the TF list, and
   `system("gsutil cp <https gencode gtf> .")` (`:79`) — `gsutil cp` cannot fetch
   an `https://` URL, and `rtracklayer::import` was already reading the URL
   directly. Both replaced by manifest staging.
3. Duplicate `gencode_V45_tpms` definition (`:19` and `:85`) collapses to one
   manifest key; the commented alternate paths (GENCODE v48 GTF, `prod-drc-broad`
   TPMs) are dropped.
4. `stat(log10(count))` → `after_stat(log10(count))` (deprecated ggplot2 form).
5. All `options(repr.plot.*)` (notebook-only) removed.
6. Library block: drop `plyranges` (no plyranges verbs are used); add `enrichR`,
   `hexbin` (for `geom_hex`) and `broom`; keep `ggrepel` (the hemoglobin extra
   needs it). Adopt the repo convention — `showtext` + Inter + one `DPI` constant
   feeding both `showtext_opts()` and every `ggsave()` — folding the original's
   `panel.border` theme into the `SZ_*` design block.
7. `compute_mean_TPM` computes `SE = sd(value) / dplyr::n()`, which is `sd/n`, not
   the standard error `sd/sqrt(n)`; it is never plotted. The mislabeled column is
   dropped rather than shipped.

### 7.3 Dropped / documented in NOTES

8. **Isoform histogram** (`:291–299`) reads `isoform_results`, a variable that is
   never defined (its source path is commented out at `:22`), so it errors. It is
   dropped from the pipeline; NOTES records that it can be reinstated by adding an
   isoform-results input to the manifest.
9. **`GO_annotations.csv`** (`:300–304`) is downloaded and `head()`-ed but nothing
   consumes it. It is kept as a manifest input and a documented read hook in NOTES
   (not shipped as a dead `head()` in a panel); wire it into an analysis if needed.

## 8. Input manifest

`SuppFig1/inputs.tsv` — columns `key`, `local_subpath`, `gs_uri` (`-` =
local-only). Readers other than `data.table::fread` are applied in the builders.

| key | local_subpath | reader | origin |
|---|---|---|---|
| `aou_tpms` | `expression/aou_rnaseq_121624.gene_tpm.fixed.gct.gz` | `fread(skip = 2)` | `PRIVATE_GCS_URI` (controlled-access) |
| `gtex_tpms` | `external/gene_tpm_v10_whole_blood.gct.gz` | `fread(skip = 2)` | `https://storage.googleapis.com/adult-gtex/bulk-gex/v10/rna-seq/tpms-by-tissue/gene_tpm_v10_whole_blood.gct.gz` (public) |
| `gencode_gtf` | `reference/gencode.v45.annotation.gtf.gz` | `rtracklayer::import` | `https://ftp.ebi.ac.uk/pub/databases/gencode/Gencode_human/release_45/gencode.v45.annotation.gtf.gz` (public) |
| `tf_list` | `reference/TF_names_v_1.01.txt` | `fread(header = FALSE)` | `https://humantfs.ccbr.utoronto.ca/download/v_1.01/TF_names_v_1.01.txt` (public) |
| `go_annotations` | `reference/GO_annotations.csv` | `fread` | `PRIVATE_GCS_URI` (hook only — see §7.3) |

Only `aou_tpms` (and `go_annotations`) are controlled-access; the three public
`https` inputs self-stage via the loader extension (§4). `external/` and
`reference/` are already in the root `.gitignore` from earlier figures; the staged
`expression/` dir is added.

## 9. Testing

The controlled-access AoU TPMs are unavailable locally, so validation mirrors the
figure cleanups:

- A `SuppFig1` fixture builds mock AoU / GTEx GCT TPM matrices and a small GENCODE
  gene-type table, so `compute_mean_TPM`, `merged_tpms`'s join, and the panel
  filtering (protein-coding / TF / lncRNA / gene-type) are testable on real
  frames. `plot_gene_comparison`'s correlation/detection data prep is asserted.
- A `common/manifest.R` test covers the new `https` staging branch using a
  `file://`/local stand-in (no network).
- `tests/test_suppfig1_assembly.R` asserts the rendered `A–F` tag sequence,
  reusing the proven grid-grob extractor.
- `rtracklayer::import`, the `enrichR` HTTP call, and `download.file` from real
  URLs are exercised only where the package/network is available; otherwise
  parse-checked. `enrichR` and `hexbin` are installed for local runs.

The real end-to-end run is `Rscript suppfig1/run_all.R` from the project root on
the Workbench.
