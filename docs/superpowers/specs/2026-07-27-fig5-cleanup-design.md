# Fig5 cleanup — design spec

*2026-07-27. Follows `docs/figure-cleanup-playbook.md`; modelled on Fig4 / SuppFig1.*

## 1. Scope

Figure 5 covers rare-variant eQTL constraint and sequence-model variant-effect
dissection. Seven panels in two blocks:

- **A–C — population/constraint view** of fine-mapped rare eQTLs at ClinGen genes:
  - **A** fine-mapped rare ClinGen variants by ancestry (AD/AR facets, novel-vs-ClinVar
    shading) over a per-inheritance ClinVar-classification proportion bar. *(patchwork:
    `ancestry_plot / clinvar_prop`)*
  - **B** `|average QTL effect|` by variant-effect category (Control/AD/AR ×
    Aggregate/Decreasing/Increasing) with 95% CI. *(single ggplot)*
  - **C** log₂ aFC of the strongest decreasing variant per gene, top 7 per AD/AR
    (HEXA, MLC1 forced in). *(single faceted ggplot)*
- **D–G — two worked mechanism examples:**
  - **D** ACVRL1 promoter fine-mapping: regional PIP + zoom inset + gene-model track. *(patchwork)*
  - **E** ACVRL1 PromoterAI base-resolution mechanism (signed-square y-axis). *(ggplot/patchwork)*
  - **F** SPR element fine-mapping: regional PIP + zoom inset + gene-model track. *(patchwork)*
  - **G** SPR Borzoi multi-track browser + CTCF attribution logo. *(cowplot object)*

Source material: the untracked `Fig5_QTL_paper/` scripts (`PlotFigure5.R`,
`acvrl1_panels.R`, `spr_browser_panel.R`); the 2,129-line `PlotFigureDraft.R` is dead
and dropped. A validated, non-conformant refactor already exists (builds the exact
`Figure5.pdf`, 1,136,396 B); this cleanup re-does it to the repo conventions.

## 2. Locked decisions

| Decision | Choice |
|---|---|
| Panel count / tags | 7 leaf panels, tags **A–G** |
| **Tagging mechanism** | **Explicit `labs(tag=)` applied in `assemble.R` only** — *not* `tag_levels="A"`. Panels are a heterogeneous ggplot / patchwork-with-inset / cowplot mix that `tag_levels` cannot traverse (Panel A is a 2-plot patchwork; D/F carry zoom insets + a gene track; G is cowplot). Panels return **untagged** objects; assembly wraps each and adds its tag. Pinned by a rendered-tag test. |
| Insets (D/F) | `inset_element(..., ignore_tag = TRUE)`; gene-model track via `plot_layout`, never tagged |
| Cowplot Panel G | wrapped with `patchwork::wrap_elements()` before tagging |
| Layout | `top = A \| (B \| C)`; `bottom = (D \| F) / spacer / (E \| G)` (verbatim from the validated refactor) |
| Helpers | **folded into `00_setup.R`** as commented sections (A–C, ACVRL1 D/E, SPR F/G) — not separate `_helpers_*.R` files |
| DPI | single `DPI <- 400`, feeds `showtext_opts()` + every `ggsave()` |
| Font | Inter via `showtext`, `sans` fallback |
| Panel B statistic | keep `mean(|posterior_mean|)` ± `1.96·sd/√n` (a real SE, and it *is* plotted as the CI). Note that B plots `|posterior_mean|` (SuSiE effect), not `log2_aFC`. Preserve. |
| `nohom` (private) | Panel C degrades gracefully when `NoHomozygoteVariants.txt` is absent (ranks strongest decreasing variant per gene without the filter), with a `message()`. It is controlled-access → never committed. |

**Resolved (2026-07-27) — result-affecting, §7.1 item 1:** the ClinGen
`gene_assignments` join in `variant_effect_by_inheritance` fans out a gene that has
**both an AD and an AR** ClinGen entry into two rows, so that gene's rare eQTL is
counted under *both* inheritance classes in Panels B and C. **Decision: PRESERVE**
(matches the published figure) + document the double-count in `NOTES.md`.

## 6. Panel decomposition & assembly

| Panel | Object | Type | Builder | Content |
|---|---|---|---|---|
| A | `A.rds` | patchwork | `build_panelA` | ancestry stacked bars (AD/AR) + ClinVar-prop bar |
| B | `B.rds` | ggplot | `build_panelB` | \|avg QTL effect\| by category, 95% CI |
| C | `C.rds` | ggplot | `build_panelC` | log₂ aFC strongest-decreasing per gene |
| D | `D.rds` | patchwork | `plot_finemapping_with_inset` | ACVRL1 PIP + inset + gene track |
| E | `E.rds` | ggplot | ACVRL1 PromoterAI builder | base-resolution promoter effect |

`assemble.R` reads the 7 objects, applies tags explicitly (ggplots via `labs(tag=)`,
patchworks via `+ plot_annotation(tag_levels=…)` scoped to that sub-object *or* a wrapped
`labs`, cowplot G via `wrap_elements() + labs(tag="G")`), composes the layout, and writes
`Figure5.pdf` (DPI) + `Figure5.png` (showtext toggled to 100).

## 7. Defects

### 7.1 Data-correctness (→ NOTES.md with original line refs)
1. **Fan-out ClinGen joins** — `variant_effect_by_inheritance` (`PlotFigure5.R:127`) and
   `build_panelA` (`:217`) `left_join` on non-unique keys (many-to-many warnings). **Preserve
   original behavior**; add `relationship=` assertions only where genuinely many-to-one;
   document the AD+AR double-count. *Awaiting human decision (§2).*
2. **`ref`-column data-masking** — SuSiE table has a `ref` column that shadows
   `reference$…` under dplyr masking; extract `clingen_genes`/`genebayes` to locals before
   the pipe. Behavior-preserving; documented.
3. **Panel B statistic** — `|posterior_mean|` (not `log2_aFC`) is what B plots; the SE is a
   real SE and is drawn as the 95% CI. Preserve; note the column choice.

### 7.2 Cleanup (no result change)
- `rtracklayer::import` namespaced (never attach — it masks dplyr `rename`/`slice`/`desc`).
- Fold `_helpers_*.R` → `00_setup.R`; remove `Fig5/` (uppercase) self-refs → `fig5/`.
- **Move tagging out of builders into `assemble.R`** (the validated refactor self-tagged in
  builders); panels return untagged objects.
- Single `DPI` constant; pt (`element_text`) vs mm (`geom/annotate`) kept distinct.
- Blank placeholders (if any) via `theme_void(base_family = FONT)`.

### 7.3 Dropped
- `PlotFigureDraft.R` (2,129 lines, referenced nowhere) — not carried over.
- `options(repr.plot.*)` and other notebook-only idioms.
